# vashishtkumar99.github.io

My personal site. Hand-built, no frameworks, no build step — plain HTML, CSS, and JS.

Still very much a work in progress. I use it as a running home base for whatever
I'm building, learning, or managing at the moment, so expect it to keep shifting.

## What's here

- **Home** — about, career, interests, now, writing preview, contact
- **Vibe Coding** — small tools I build with AI when a problem annoys me enough
- **DJ Journey** — teaching myself to DJ with an AI-built curriculum, the full plan,
  and a virtual DDJ-FLX4/FLX2 you can click through (or connect the real thing to)
- **Writing** — short essays on building things, music, and how systems behave

## Structure
```
index.html            home (about, career, interests, now, writing preview, contact)
vibe-coding.html       projects
dj.html                DJ journey overview
dj-plan.html           full 12-week DJ curriculum
dj-controller.html     interactive virtual DJ controller
writing.html           blog index (search + categories)
writing/               individual posts
404.html               not-found page
styles/                main.css (tokens + components), animations.css, responsive.css
js/                    app.js (behavior + post data), animations.js (scroll effects)
assets/                resume PDF, favicon, images
.claude/               agents + project notes for AI-assisted edits
```
